## ML System Design Framework (Quick Summary)

| Step | Time | Focus |
|------|------|-------|
| 1. Clarify | 5 min | Requirements, constraints, metrics |
| 2. Architecture | 5-10 min | End-to-end system diagram |
| 3. Features | 5-10 min | Data sources, feature engineering |
| 4. Training | 3-5 min | Algorithm choice, infrastructure |
| 5. Serving | 5 min | Latency, throughput, deployment |
| 6. Monitoring | 5 min | Drift, alerts, retraining |
