# ML Interview Playbook

Complete interview preparation for SDE-ML, MLE, and AI Engineering roles at top tech companies.

Built with [VitePress](https://vitepress.dev/).

## Content

| Section | Description |
|---------|-------------|
| **ML Interview FAQ** | 74 interview Q&A with sample answers and 32 visualizations |
| **ML Fundamentals** | Linear/Logistic Regression, Decision Trees, SVM, KNN, Neural Networks, Clustering |
| **SDE Coding** | 150+ problems across 14 categories with step-by-step solutions |
| **ML System Design** | 6-step framework, real interview questions, key phrases |
| **ML Coding** | KNN, K-Means, CNN implementations in Python/NumPy/PyTorch |
| **Behavioural** | Googleyness traits, STAR stories, common questions |

## Development

```bash
cd docs

# Install dependencies
npm install

# Start dev server
npm run docs:dev

# Build for production
npm run docs:build
```
