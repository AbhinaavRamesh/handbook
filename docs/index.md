    <div class="topics">Arrays, Trees, Graphs, DP, Heaps, Stacks, Linked Lists, Binary Search, Recursion, Backtracking</div>

  <a href="/ml-fundamentals/" class="track-card">
    <h3>ML Fundamentals <span class="badge">Theory</span></h3>

    <div class="topics">Neural Networks, Transformers, Reinforcement Learning, CNNs, Attention Mechanisms</div>
  </a>
  <a href="/genai-engineering/" class="track-card">

    <div class="topics">RAG, Prompt Engineering, Fine-tuning, LLM APIs, Vector Databases</div>
  </a>
  <a href="/ml-coding/" class="track-card">
    <h3>ML Coding <span class="badge">Implementation</span></h3>
    <p>Implement machine learning algorithms from scratch. Pure Python, NumPy optimized, and PyTorch production variants.</p>
    <div class="topics">KNN, K-Means, Convolutions, Gradient Descent, Loss Functions</div>
  </a>
  <a href="/ml-design/" class="track-card">

  </a>

    <div class="topics">STAR Method, Leadership Principles, Conflict Resolution, Project Stories</div>
  </a>
