# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive. Harassment, personal attacks, and other unwelcome behaviour are not tolerated.

To report a concern, contact the maintainer at **contactabhinaav@gmail.com**. Reports will be handled confidentially.
