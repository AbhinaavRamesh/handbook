# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful and constructive. Harassment, personal attacks, and other unwelcome behaviour are not tolerated.

To report a concern, please [open an issue](https://github.com/AbhinaavRamesh/handbook/issues/new/choose) using the **Report a Code of Conduct concern** template. Issues are public, so if the matter is sensitive you can instead report it privately through GitHub's [report abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) flow, and share only what you're comfortable making public.
