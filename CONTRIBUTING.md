# Contributing

Thanks for your interest in improving the handbook! Content corrections and topic suggestions are welcome.

## Scope

- **Typos, factual errors, broken links**: open a PR directly, or file an issue if you'd rather not.
- **New topics or large sections**: please [open an issue](../../issues/new/choose) first so we can align on scope before you invest effort — this is a single-maintainer project with limited review bandwidth.

## Run locally

```bash
cd docs
npm install
npm run dev        # local dev server
npm run build      # the same check CI runs on your PR
```

## Content conventions

- Markdown pages live under `docs/<section>/` (e.g. `docs/ml-fundamentals/`); new pages must be added to the sidebar in `docs/.vitepress/config.ts`.
- Math uses MathJax (LaTeX syntax); diagrams use Mermaid code blocks.
- Figures are generated by the Python scripts that live alongside the content (e.g. `docs/scripts/`, `docs/genai/assets/scripts/`). Regenerate images by re-running the relevant script rather than hand-editing them.

## PR process

1. Branch from `main`.
2. Open a PR — direct pushes to `main` are disabled.
3. The `pr-build` check (a full VitePress build) must pass before merge.
